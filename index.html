Unix command lines with Lulu 🐧

Score: 0 / 0

Lulu the Penguin lives in the Linux operating system. With it, you can practice using the CD-command (change directory) in a Unix-based terminal. After pressing the start button, you'll see Lulu's folder tree.
Two folders will be randomly selected:
1) the terminal's current folder,
2) the target folder.
Enter the command that will move the terminal from the current to the target folder and score points for correct answers.
Good luck!
